**Source Location for various files downloaded by the manager at runtime, These can be added to/edited without the application needing an update**

- **Custom Handlers** - Game handlers created in the define custom game menu.
- **Localisation** - Language files
- **Plugins** - External wizard tools (Not currently used in v2)
- **Profiles** - Pre made modlists
- **Synthesis** - Nuget Config, Fixes errors when using synthesis via proton
