# MO2 Icons

An icon-only Amethyst plugin using the 13 images supplied in `mo2icons`.
The images are copied unchanged; this pack contains no Python code.

Replaces loose-file and archive conflict icons, warning icons, notes,
endorsements, cleaning, and search. Other manager icons and game images
retain their existing appearance.

Open Plugins -> Browse plugins, select MO2 Icons, and choose Settings.
Each icon has its own switch, enabled by default. Save and restart Amethyst
to apply changes. A disabled replacement lets another enabled icon pack
supply that icon, or falls back to Amethyst's bundled image.

Manage the whole pack through the same browser. Enable, disable, update,
and removal changes apply on the next restart. Saved settings are retained
when the pack is updated.

Requires Amethyst 2.6.0-beta.3 or newer with plugin settings and conditional
icon override support.
